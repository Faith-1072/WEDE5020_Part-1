\# Glamoured – Online Wig Store



\## Project Overview

Glamoured is an online wig and hair-care store designed to empower women through beauty, confidence and self-care.



The website allows customers to explore wig products, learn about the business and submit enquiries.



\## Website Features

\- Responsive website design

\- Dynamic product listings

\- Product search and category filtering

\- Interactive FAQ accordion

\- Wig image gallery with lightbox

\- Nationwide delivery map

\- Enquiry form with validation

\- Contact page

\- SEO optimisation



\## Technologies Used

\- HTML5

\- CSS3

\- JavaScript

\- Leaflet.js

\- OpenStreetMap

\- Netlify

\- Home
